一、v4 修了什么（针对「点图标黑屏一下就退回快捷方式」）

问题原因v4 处理
Wine 注册表缺 Blizzard 项
主因		3DM 绿色版在 PC 上能跑，靠的是宿主 Windows 注册表里已有的 Blizzard Entertainment\Diablo II，或由 D2Loader 绕过。手机容器是全新的 Wine，user.reg 里完全没有 InstallPath / Save Path / CDKey，1.13c 启动读不到就直接退出在容器模板的 user.reg 与 system.reg 预写这些键（HKLM 另补 Wow6432Node 视图），并预建 Save 目录
错误框被吞掉旧参数里的 -nonotify 是「关闭错误信息报警」，崩溃时不弹任何提示，只表现为黑屏一下退回，无法判断原因全部快捷方式去掉 -nonotify 与 -notitle；现在若出错会弹出 Wine 错误框，把框里的文字记下来即可定位
游戏路径带空格和括号旧路径 C:\Program Files (x86)\Diablo II，Winlator 的 winhandler.exe 对空格用 \ 转义，但 (x86) 容易被命令行解析当成控制字符一体化版游戏目录改为 C:\DiabloII（无空格无括号）
启动器只有 D2Loader 一种D2Loader / PlugY 都靠跨进程内存注入 Game.exe，在 Wine + Box64 wow64 下最容易失败（PC 上常见 "read process memory failed"）。而原版启动脚本既有 PlugY 也有 Game.exe预置 5 个编号快捷方式，覆盖主程序直连、PlugY、D2Loader、无 -direct、D2DX 五条路径，见第三节
另外说明：PC 版 Game.exe 是 32 位 x86 Win32 程序、无源码，无法编译成 ARM 原生应用。本 APK 是把 Winlator（Wine + Box64 + PRoot）改造成专用客户端，在手机上以兼容层运行 PC 版，画面、存档、Mod 与电脑版一致。高清补丁是外挂文件（glide3x.dll 等），不带 -3dfx 走原版渲染路径是允许的，不影响启动。

二、快速开始

⚠ 打开 App 后「快捷方式」页是空的？这是正常现象。「快捷方式」页只显示已创建容器里的桌面文件，首次启动只装 Wine 运行环境、不会自动创建容器。关键顺序：先建容器 → 等解压完成 → 再回「快捷方式」页。

一体化版（推荐）

  1. 把一体化 APK 拷到手机安装；系统提示"未知来源"时允许一次。
  2. 打开「暗黑破坏神II 1.13c」，等首次初始化解压 Wine 环境（约 1–3 分钟，保持亮屏）。
  3. 切到「容器」页 → 点 + →「新建容器」，分辨率 800x600，其余默认。要展开约 1 GB 游戏本体，等创建完成提示出现（2–8 分钟），中途别切后台或锁屏；手机留 ≥ 3 GB。
  4. 回「快捷方式」页，会看到 01～05 五个图标，从 01 开始按顺序点，哪个能进游戏以后就固定用哪个。

游戏文件位置：一体化版 C:\DiabloII，轻量版 D:\DiabloII；存档在 ...\DiabloII\Save\，与 PC 版通用。

轻量版（新建容器秒完成，最稳）

  1. 安装轻量版 APK；把 DiabloII_数据包.zip 解压出 DiabloII 文件夹，整个放到手机 Download/DiabloII（文件夹里直接能看见 Game.exe）。
  2. 也可用数据线一键完成：python port/scripts/deploy.py（需 USB 调试）。
  3. 「容器」页点 + →「新建容器」（800x600）。轻量版模板仅约 7 MB，几秒完成。Winlator 默认把 D: 盘映射到手机 Download，所以游戏路径是 D:\DiabloII。
  4. 回「快捷方式」页，同样从 01 开始逐个点。

三、五个启动图标，按编号试

Winlator 的快捷方式名直接取 .desktop 文件名，所以用 ASCII 编号命名，方便口头反馈「我试到 03 了」。

图标名可执行文件 / 参数为什么准备这一条
01-Game-direct-w
先点这个		Game.exe -direct -w直连游戏主程序，完全不做进程注入，兼容层下成功率最高；-direct 保证中文，-w 窗口模式
02-PlugY-direct-wPlugY.exe -direct -wPC 版整合包既定的启动方式（大箱子、共享仓库）。PlugY.ini 的 Param=-direct 已配好
03-D2Loader-direct-wD2Loader.exe -direct -wv3 用的免 CD 加载器，保留作对照（已去掉会吞错误的 -nonotify）
04-Game-w-onlyGame.exe -w不带 -direct，用于判断崩溃是否由中文 Data\ 目录引起；界面会变英文属正常
05-Game-3dfx-direct-wGame.exe -3dfx -direct -wPC 版 D2DX 高清渲染路径。Wine 下需 dxgi.dll/d3d11.dll，多数机型会崩，仅作最后对照
参数三条铁律：
-direct 必须加——中文版从 Data\ 加载汉化，去掉会变英文/乱码；
-txt 绝对不能加——这个破解版加了该参数会在片头后直接退出；
-nonotify 绝对不能加——它会屏蔽错误弹窗，让崩溃原因不可见。
五条快捷方式都已按此配好，正常情况无需自己改参数。

五、排障

现象处理
点击游戏图标黑屏一下，退回「快捷方式」页先确认已覆盖安装 v4 且删掉旧容器重建（v4 的注册表与新路径只在新建容器时生效）。然后按 01 → 05 顺序逐个点。v4 已去掉 -nonotify，若再次失败应会弹出 Wine 错误框——请把框里的文字抄给我，那是最直接的证据。同时把容器 Box64 预设改成 Stability 再试一次

「快捷方式」页空白没创建容器。到「容器」页点 + 新建，等解压完成再回来；若已有容器，长按删除后重建。v4 的空列表文案已是中文指引

黑屏 / 花屏（能进游戏但画面异常）换图形驱动（VirGL ↔ Turnip/Zink）；容器分辨率固定 800x600；不要加 -3dfx（除非在试 05）

反馈时请给我这三点，能一次定位：①试到哪个编号（01～05）；②是否有错误弹窗、原文是什么；③手机芯片型号 + 容器里 Box64 预设档位。没有错误弹窗也没关系，说明是进程直接崩，我会改走日志抓取。
兜底：手动抓控制台输出
